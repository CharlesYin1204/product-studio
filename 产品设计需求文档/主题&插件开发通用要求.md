# 主题与插件开发通用要求 V1.0.1

此文档为首次建设同步建立的规范。

- Vue 3 组件承担交互，CSS 统一维护在 web/src/style.css；主题不得改变业务工作流。
- 第三方模型、Lark、Telegram 调用全部位于服务端；浏览器不获取密钥，密钥不得进入下载内容与日志。
- 外部 URL、模型、Chat ID、通知话术来自管理员配置；业务对象来自 MySQL，不把样本硬编码为权限策略。
- 原型源码为不可信输入，仅在隔离 iframe 执行；不能执行生成的 Node.js 代码或任意 SQL。
- 标准件以项目 template 内容版本化保存，复用是复制源码，不改写原始模板。
- 新接入必须具有真实错误态、未配置态，不可显示模拟成功结果。
- 当前不支持动态安装服务端插件；扩展须作为经过审核的服务端模块接入。
- Codex CLI 作为受控服务端能力接入，不作为浏览器插件或可配置外部 URL；认证文件仅归服务账号可读，运行使用只读沙箱和独立临时目录。插件不得读取、复制或回显 Codex 认证信息，也不得绕过产品的项目权限、暂停、超时和审计流程。
