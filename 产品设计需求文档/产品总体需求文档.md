# 序构 · AI 产品经理工具

版本：V1.0.1，2026-09-18。需求来源：同目录 instruction.md（原文保留）。

## 产品目标
面向同时管理多个产品的产品经理，将需求规划、PRD、技术文档、交互原型、团队评审和版本追溯集中到同一项目空间。前端 Vue 3，后端 Node.js + NestJS，数据保存到 MySQL。无演示账号、无模拟项目、无随机统计；初始项目与 18 条需求来自用户提供的 instruction。

## 信息架构与流程
登录 → 工作台 → 产品项目 → 需求池 → 产品文档 / 原型设计 → 项目评审 → 版本规划。
辅助入口：组件模板、AI 产品助手、设置与集成。

1. 工作台：当前项目选择、真实内容统计、项目卡片、待处理需求、操作动态。
2. 产品项目：新建、编辑项目名称与目标，项目成员独立授权。项目状态支持 active / archived，归档接口已提供。
3. 需求池：看板与列表切换、搜索、状态、优先级、模块、负责人、目标版本、截止日期、来源和描述。状态为待规划 / 已规划 / 进行中 / 待评审 / 已完成。
4. 文档：PRD / 技术文档 / 笔记，Markdown 编辑与安全预览、关联需求、下载 Markdown、版本记录与历史载入。
5. 原型：HTML、Vue SFC、React TSX；前台 / 后台分类、模块说明、需求关联；源码编辑、编译预览、手机尺寸、全屏演示、ZIP 下载。
6. 真实交互：每个原型拥有独立的 MySQL 数据集合。window.pmData 提供 list/create/update/delete；权限在服务端校验；不执行 AI 生成的服务端代码。外部分享只读数据，编辑成员可写。
7. 评审：按文档、需求或原型记录评论，可标记解决、重新打开。外部评审链接可设置只读 / 可评论及 7/30/90 天有效期，负责人可撤销该内容的全部链接。
8. 版本：规划日期、发布说明、关联需求；发布时保存需求快照，每次修改仍生成新的历史版本。
9. AI：管理员配置多个兼容 Chat Completions 的模型；项目上下文与具体需求/文档/原型关联；真实生成 PRD、技术文档、源码。多 Agent 为同一选定模型分别执行需求分析、技术评审、交付三角色的顺序协作；不宣称并行或独立模型协作。
10. 标准件：页面导航、数据管理，以及可创建、编辑、复用的项目模板；原型可保存为模板。
11. Lark：国际版 OAuth 绑定、token 加密保存与刷新、读取 /docx/ 文档原始文本、创建并写入新文档。当前不包含 Wiki 解析和富文本双向同步；导出按文本块保留 Markdown 内容，不伪装成原生富文本。
12. Telegram：配置 BotFather 创建的机器人 Token、多个 Chat ID、事件与消息模板；真实新需求和评审意见触发通知，并记录成功/失败。不会在未启用时发送。

## 权限
- 空间管理员：配置集成、AI 模型和成员账号。
- 项目负责人：管理项目成员、创建/撤销分享；拥有编辑和评审权限。
- 编辑：增改项目内容与原型数据，可评论。
- 评审：读取内容、提交意见，不可写原型数据。
- 只读：仅查看。
- 外部分享：仅访问被分享的内容，不暴露项目需求、聊天记录、账号或密钥。

## 数据与安全约束
会话使用 HttpOnly / SameSite Cookie；密码 bcrypt；密钥 AES-256-GCM 加密。JSON 接口执行来源、输入与项目权限校验，查询参数化；文档 HTML 消毒；原型 iframe sandbox=allow-scripts allow-forms，独立 CSP 限制网络。保存采用版本号与数据库行锁，冲突返回 409，避免静默覆盖他人修改。

## 环境与验收边界
生产入口由服务器 Nginx 代理，NestJS 仅监听回环地址；systemd 保持运行。业务数据库已有真实连接。AI / Lark / Telegram 的凭据未由用户提供，因此目前交付真实接口和配置流程，第三方端到端联调尚未完成；不得将“接口已编写”描述为“外部已连接”。
目前服务器使用 IP + HTTP，未提供可签发证书的域名；后续配置 HTTPS 域名时同步 PUBLIC_URL、Cookie secure 和 Lark 回调白名单。在线文档内保留明确来源，产品数据不使用浏览器本地存储伪装持久化。

## 创作暂停与菜单折叠（2026-09-18）
- AI 创作过程中提供「暂停创作」，由服务端中断当前模型连接，并停止后续 Agent 调用；指令保留，对话标记 paused。暂停不删除已经完成的内容。
- 兼容模型接口不支持原位置挂起恢复，因此「重新创作」会用保留的输入发起新请求；界面明确说明，不伪装为原请求续传。模型供应商是否停止内部计算取决于其服务，工作台停止连接及结果保存。
- 正在提交保存的成果不再接受暂停，返回明确状态，避免已保存内容被错误标记暂停。暂停权限按当前用户、项目和请求分别校验。
