# 接口文档 V1.0.1

正式入口 http://154.40.47.111:8080，基础路径 /api，JSON 编码。分享链接与 Lark 回调使用 PUBLIC_URL（包含端口）生成。受保护接口使用 pm_session Cookie，无需在前端保存 token。非 GET 请求发送 Content-Type: application/json。未登录 401，无权限 403，不存在 404，校验错误 400，保存版本冲突 409，登录限流 429。响应错误结构 {"message":"原因"}。

## 身份与项目
| 方法 | 路径 | 请求 / 说明 |
|---|---|---|
| POST | /auth/login | email, password；设置 HttpOnly 会话 |
| GET | /auth/me | 当前账号 id/name/email/admin |
| POST | /auth/logout | 撤销当前会话 |
| POST | /auth/password | current, password；撤销其他会话 |
| GET/POST | /projects | 列出可见项目 / 创建 name,description |
| PATCH | /projects/:id | name,description,status；负责人 |
| GET/POST | /projects/:id/members | 列表 / email,role(editor/reviewer/viewer) |
| DELETE | /projects/:id/members/:user | 移除非负责人 |
| GET/POST | /users | 管理员列表 / 创建 email,name,password（至少12位） |

## 内容、版本与评审
| 方法 | 路径 | 请求 / 说明 |
|---|---|---|
| GET/POST | /projects/:id/items | 列表 / {kind,title,body} |
| PATCH | /items/:id | {kind,title,body,version}；version 必须匹配当前版本 |
| GET | /items/:id/revisions | 全量历史正文、版本和操作者 |
| GET/POST | /items/:id/comments | 列表 / {content} |
| PATCH | /comments/:id | {resolved:boolean} |
| GET | /projects/:id/activity | 最近40条项目动态 |
| GET | /items/:id/export | 文档 Markdown；原型/模板 ZIP |

kind 与 body：
- requirement：description、status(backlog/planned/progress/review/done)、priority(high/medium/low)、module、release、assignee、dueDate、source。
- document：type(prd/technical/note)、content、source、requirementId、larkId。
- prototype：language(html/vue/react)、surface(frontend/admin)、module、description、source、requirementId。
- template：language、category、description、source。
- release：description、status(planned/progress/released)、dueDate、requirementIds；服务端发布时生成 snapshot。

## 原型运行
- GET /items/:id/preview：编译结果 {html}；不执行服务器代码。
- GET /items/:id/render：独立受限 CSP 的 HTML 预览，须在 sandbox iframe 中打开。
- POST /items/:id/data：{action:list/create/update/delete,collection,data?,id?}。
- list 返回 [{id,data}]，create 返回 {id,data}，update/delete 返回 {ok:true}。
- 生成原型通过 window.pmData(action,collection,data?,id?) 使用父页面受控桥接；父页面校验消息来源，服务端按项目角色与原型 ID 隔离。
- ZIP 包含原始源码、编译后的 index.html、真实数据快照 data.json 与接入说明；离线 index.html 可读取真实数据快照；独立部署写入需要实现 pmData 适配。

## AI
- GET/POST /models：列表不返回 API Key；新增 name/base_url/model/api_key，仅管理员。
- DELETE /models/:id；POST /models/:id/check：发出真实短请求验证连通性，可能产生供应商费用。
- POST /projects/:id/generate：modelId,prompt,itemId?,kind(chat/prd/technical/prototype),language?,multiAgent?。返回 content 与 item；失败输入保留 failed 状态。
- GET /projects/:id/messages：项目对话记录，可按 item_id 在前端定位。
- 上游协议：POST {base_url}/chat/completions，Bearer 鉴权，model/messages/stream:false。参考 https://gpt-best.apifox.cn/api-139393491。

## 分享与集成
- POST /items/:id/shares：{role:viewer/reviewer,days:1..90}，返回 url。DELETE 同路径撤销此内容所有链接。
- GET /share/:token：仅分享内容与评论；GET /share/:token/render：原型预览。
- POST /share/:token/comments：{author,content}，仅评审链接；POST /share/:token/data：仅 list。
- GET /settings：脱敏配置及通知日志；POST /settings/lark：appId,appSecret?；POST /settings/telegram：token?,chatIds,enabled,events,template。
- POST /lark/connect 返回国际版授权地址；GET /auth/lark/callback：验证一次性 state 后换取用户 token。
- POST /projects/:id/lark/import：url,title，读取 /docx/ 文档为本地文档。
- POST /items/:id/lark/export：新建 Lark 文档并按段落写入，返回 documentId。若分批写入失败，错误保留已创建文档 ID，避免隐瞒部分成功。

所有密钥只允许通过管理员配置写入，读接口不返回原值。Telegram 不提供未经配置启用的外发行为。外部 API 失败不得返回伪造成功结果。

## V1.0.2 更新
- POST /projects/:id/generate 的 kind 新增 note；原型增加 surface(frontend/admin)，其余协议不变。
- POST /lark/connect：启动或复用当前账号的注册/设备授权流程，返回 {phase,url,expiresAt,message}，前端打开真实 Lark 授权链接。此接口不需要客户端提交密钥。
- GET /lark/status：仅当前账号可见的流程状态，phase 为 idle/starting/registering/authorizing/complete/failed/expired。
- POST /lark/cancel：取消当前账号尚未完成的授权。
- POST /lark/disconnect：删除本地保存的用户 token；不删除已导入文档，完整撤回平台权限仍需用户在 Lark 完成。
- 注册通过 @larksuiteoapi/node-sdk registerApp，使用最小权限声明和 createOnly 专用应用；文档设备授权基于官方 larksuite/cli 的 Device Authorization 协议实现。服务端使用用户独立应用凭据刷新 token。
- LEGACY_ORIGINS 仅兼容本产品旧入口，不启用通配 CORS。

## AI 生成可靠性更新
AI_TIMEOUT_MS 控制单次模型调用等待时间，默认/最大 300000 毫秒；多 Agent 最多三个顺序请求，代理等待 960 秒。鉴权、限流、连接、超时、响应格式、输出截断分别返回具体错误。原型生成先编译校验再持久化；失败请求标记 failed，并保留用户指令和已经返回的模型对话。环境配置修改后需重启服务。

## 创作暂停接口
- POST /projects/:id/generate 可附带 requestId（UUID），用于识别该次生成。服务端对话 ID 独立生成，不信任客户端作为数据库记录主键。
- POST /projects/:id/generate/:requestId/pause：仅当前用户在该项目发起的活动任务可暂停；需要编辑权限。中断模型请求，返回 {paused:true}；原 generate 同样返回 {paused:true}，消息持久化为 paused，前端保留输入。
- 已结束、尚未注册或正在保存的请求返回 409，并说明原因。旧客户端不提供 requestId 时仍可生成。
- 暂停后重新创作使用新的 requestId，属于新的模型调用；不宣称上游支持断点续传。活动任务保留在单实例进程中，服务重启后按现有规则将未完成 pending 记录标为 failed。

## 独立交互预览
- GET /items/:id：读取当前用户有权限访问的内容，复用项目权限校验；未登录 401。
- /preview/:id 为登录后的前端独立原型预览入口，可带 device=phone；默认 PC。使用现有 /items/:id/preview、/render、/data 接口，数据读写权限不变。
- 窗口数据桥仅接收当前 iframe 的 pm-data 消息，按当前原型 ID 发起同源请求；关闭原创作窗口不影响独立预览。新窗口链接使用 noopener noreferrer。

## 免登录与加密分享
- POST /items/:id/shares 新增 password（可选，空字符串表示无密码；非空4至64字符）。仍要求项目负责人，返回独立 url；密码不包含在 URL。
- POST /share/:token/unlock：{password}，无需工作台登录。正确后设置路径限定的 HttpOnly 分享会话 Cookie，最长1天；密码错误403，尝试过多429。
- GET /share/:token、GET /share/:token/render、POST /share/:token/data、POST /share/:token/comments：无密码链接直接访问；密码链接未解锁返回403，过期/撤销返回404。解锁不赋予项目写入权限。
- pm_shares 新增可空 password_hash；pm_share_sessions 存储会话摘要、分享摘要与到期时间，撤销分享通过外键级联删除会话。兼容现有无密码分享。

## Codex 本机模型
- GET /models 返回 `id、name、base_url、model`。服务启用本机 CLI 且认证文件存在时自动返回 `name=Codex · 服务器本机、base_url=codex://local` 的模型；该内部地址只用于服务端路由，API Key 不返回浏览器。
- POST /projects/:id/generate 的 `modelId` 可指向该模型，参数和返回结构与其他模型一致。后端以 `codex exec --json ... -` 发送提示词，仅读取 JSONL 中最终 `agent_message`；命令超时、无有效文本、非零退出和取消均转换为现有生成错误/暂停状态。
- 本机 Codex 在只读沙箱和独立工作目录运行，不执行产品生成的 Node.js/SQL；上下文与成果仍由产品服务负责读写和保存。
